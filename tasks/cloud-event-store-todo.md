# `cloud-event-store` 任务清单

> 前置条件：`SPEC-cloud-event-store.md` 与 `tasks/cloud-event-store-plan.md` 已确认。
>
> 边界：本清单可创建本地源码、测试、文档与 migration 工件；不创建 Supabase 项目、不填入项目配置、不执行远程 SQL。

## 1. 异步仓储端口的失败测试

- [ ] 为 Promise 化的餐局仓储接口写测试，证明本地仓储仍保留创建、列表、保存和删除语义。
- [ ] 定义并测试可展示的错误分类，禁止将云端失败伪装为本地写入成功。

验收：测试先失败；同步接口使用点有明确的迁移路径。

## 2. 实现异步本地适配器

- [ ] 将 `MealEventRepository` 改为异步端口，并让 `LocalMealEventRepository` 保持 localStorage 行为。
- [ ] 只改受影响的页面与测试，使本地模拟流程仍可用。

验收：异步仓储测试和现有餐局页面测试通过。

## 3. 双向聚合行映射的测试与实现

- [ ] 先写失败测试：完整八表行能恢复饭局；缺成员、孤儿候选、跨饭局投票或重复唯一键行被拒绝。
- [ ] 实现不依赖网络的反向映射，维护 camelCase / snake_case 边界。

验收：合法聚合无信息丢失，畸形数据不进入页面状态。

## 4. 云端仓储的测试与实现

- [ ] 用严格的可注入数据端口夹具测试 list、get、create/save RPC、创建者删除和错误翻译。
- [ ] 实现 `CloudMealEventRepository`；它不接收用户 ID 授权参数，也不静默回退本地。

验收：所有网络/权限/无配置失败都以可判定错误返回。

## 5. 事务 RPC migration

- [ ] 新增独立 migration，提供 security-invoker 的聚合保存 RPC、固定 `search_path`、`auth.uid()` 验证和原子子表替换。
- [ ] 复核 RPC 不授予 `anon`，不依赖浏览器 service-role 密钥。

验收：SQL 与规格一致，可审阅但不在本地或远程执行。

## 6. 页面仓储选择与状态

- [ ] 新增加载/保存/retry 状态边界：未配置时选本地；云端访客就绪时选云端；云端失败显示错误。
- [ ] 把创建与工作台的读写改为 await，保留既有 UI 和“本地模拟”标识；云端创建只写当前访客为 `creator`，3–8 人代填仅留在本地。

验收：组件测试覆盖本地、加载、云端失败和重试，不引入 Realtime。

## 7. 指南、验证与本地归档

- [ ] 更新 Supabase 指南中的 migration 顺序与在线验证缺口。
- [ ] 运行目标测试、完整测试、构建与 `git diff --check`。
- [ ] 精确暂存本模块文件并创建本地 Git 提交；不包含已有未提交文件，推送另行确认。

验收：验证命令有可复现输出；没有真实项目时明确保留 RLS/RPC 在线验证为待办。
